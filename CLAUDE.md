# Упутство за Claude

Прочитај AGENTS.md пре сваког задатка — та правила су обавезна.

- Управљач не ради у терминалу: Claude води гране, измене и Pull Request-е, а управљачу даје готов пакет са тачном путањом распакивања у самом кораку упутства.

- Сервер (Plus Hosting, дељени хостинг) нема SSH; све иде преко cPanel File Manager-а или PHP скрипте која се отвара у прегледачу.
- Сајт је статички HTML, без WordPress-а.
- Пре слања Pull Request-а покрени контролну скрипту и напиши у опису шта је промењено, зашто, по ком извору и како је проверено.
