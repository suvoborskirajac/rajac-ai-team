# Стручна провера биодиверзитета — 1. корак: спискови врста

Датум: 15. 10. 2026. · Аутор прегледа: Claude · Рецензија: ChatGPT · Одлука: управљач

Ово је преглед **назива и присуства врста** на основу наслова свих страница у каталозима (извор: контрола сајта од 15. 10. 2026). Садржај појединачних страница (опис, станиште, календар, заштита, фотографије) је 2. корак.

**Ознаке поузданости**
- **сигурно** — грешка без сумње (погрешан род, назив друге врсте, отровна/јестива замена);
- **вероватно** — назив не одговара уобичајеној српској номенклатури, треба потврдити у наведеном извору;
- **доказ** — врста може бити погрешно приказана као присутна на Рајцу; тражи се запис (Студија заштите, eBird, iNaturalist, рад, теренски налаз).

Српски народни називи се коначно проверавају у штампаним изворима: Флора Србије (Јосифовић, ур.), списак птица Србије (Лига за орнитолошку акцију Србије / Пузовић и сар.), фауна слепих мишева Србије (Паунович), дневни лептири Србије (Јакшић). Ниједна исправка се не уноси без потврде.

## Следећи кораци

1. ChatGPT рецензира овај списак.
2. Управљач одлучује о врстама без доказа: брисање или „могуће присуство“.
3. Где год је могуће, исправку потврђује стручњак за групу (миколог, ботаничар, орнитолог).
4. 2. корак: преглед садржаја сваке странице, по групама.
